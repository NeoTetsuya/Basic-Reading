# 📖 Basic-Reading — IELTS Academic Reading Master Suite

A comprehensive interactive reading analysis platform designed for IELTS Academic test preparation. Features authentic passage breakdowns, sentence structure parsing, vocabulary breakdowns, and Latin/Greek root word etymology guides.

---

## 🌟 Key Features

- **Passage-by-Passage Analysis**: In-depth breakdowns of academic texts (Environment, Biology, History, Psychology, Technology).
- **Sentence Structure Decomposition**: Visual syntax trees and parsing of complex, compound, and passive sentences.
- **Root Words & Etymology (`Roots & Meanings.html`)**: Interactive master guide to Latin and Greek roots, prefixes, and suffixes to unlock unfamiliar vocabulary.
- **Dual-Language Guidance**: Contextual Vietnamese translations, grammar notes, and IELTS question evidence mapping.
- **Interactive Directory Hub (`index.html`)**: Dynamic module selector and passage navigation dashboard.
